# PMAK、KinForm、KcatNet 评测日报

本阶段继续推进已发表 kcat 预测方法的统一评测流程，完成了 PMAK、KinForm 和 KcatNet 三个方法的接入、环境适配、输入整理、批量预测和统一指标评估。PMAK 方面，按照其“蛋白序列 + 反应 SMILES”的输入要求，从当前 benchmark 数据中构建了完整反应表示，并复用 ProtT5 与 RXNFP 分别生成蛋白和反应特征；最终 978 条基准数据中有 780 条可进入 PMAK 评测，主要缺失原因是部分反应物或产物缺少可用 SMILES，全量结果为 MAE log10 0.7227、RMSE log10 1.0091、Pearson 0.3828、Spearman 0.4303，10 倍误差内比例 0.7679。KinForm 方面，完成了官方代码、Zenodo 资源包、预训练模型和预计算蛋白特征的整理，并检查我们的 benchmark 序列是否能在官方预计算特征中找到；由于 KinForm 依赖预先算好的多种蛋白 embedding 和 binding-site 特征，当前只有 563 条样本可直接预测，415 条主要因缺少官方预计算特征而不能评测，全量可预测子集结果为 MAE log10 0.7827、RMSE log10 0.9894、Pearson 0.6028、Spearman 0.6297，10 倍误差内比例 0.7158。KcatNet 方面，完成了官方仓库接入和 kcat 预训练权重调用，按“蛋白序列 + 底物 SMILES”生成输入，复用本地 ProtT5 与 ESM2 权重，并解决了 `sentencepiece`、`torch_scatter` 与当前 PyTorch 环境不匹配的问题，其中 `torch_scatter` 已在项目本地按当前 ABI 从源码编译；最终 978 条中 977 条可评测，仅 Quinate 的错误 SMILES `192.167` 无法进入模型，结果为 MAE log10 0.6841、RMSE log10 0.9962、Pearson 0.4738、Spearman 0.5149，10 倍误差内比例 0.7789。三个方法的预测结果、评估表和未预测原因均已写入 `data/final/` 与 `reports/tables/`，并同步更新到 `reports/tables/method_eval_summary.csv` 和 `docs/kcat_benchmark_work_log.md`。整体来看，KcatNet 在当前全量可评测数据上的平均误差最低，KinForm 的相关性指标更高但覆盖率较低，PMAK 覆盖率受完整反应 SMILES 限制；后续写文章时需要同时报告评测覆盖率、误差指标和相关性指标，避免只用单一指标比较方法优劣。
